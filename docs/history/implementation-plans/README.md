# 历史实施计划

> **文档类型**：历史索引
> **状态**：Living
> **权威范围**：已执行、被替代或冻结的实施计划归档规则

## 归档条件

实施计划满足以下任一条件时可迁入本目录：

- 对应实施已经完成并通过验收；
- 计划被新的 Spec/Plan 明确替代；
- 计划被用户明确冻结，不再继续执行。

## 归档要求

- 保留原始计划内容；
- 添加原始路径、状态、冻结日期和替代文档；
- 未完成工作必须创建新的 Feature Spec，不能继续修改已冻结计划；
- 迁移后必须更新仓库内所有有效引用。
