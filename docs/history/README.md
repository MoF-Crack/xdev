# XDev 历史文档

> **文档类型**：历史索引
> **状态**：Living
> **权威范围**：旧计划、一次性执行记录和已替代文档的保存规则

## 用途

本目录保存不再作为活跃规范源、但仍具有追溯价值的文档。

## 规则

- 历史文档不得直接驱动 Agent 实现。
- 未完成需求必须提炼为新的 `specs/<编号-功能名>/spec.md`。
- 旧文档保留原始内容，并增加来源、冻结日期和替代文档信息。
- 发现历史错误时追加勘误，不通过重写伪造原始状态。

## 子目录

- `implementation-plans/`：已经执行、被替代或冻结的一次性实施计划。
