# XDev 审计与时间点报告

> **文档类型**：历史索引
> **状态**：Living
> **权威范围**：安全、质量和工程审计的归档规则

## 用途

本目录保存基于特定日期、代码基线和工具版本生成的审计报告。审计报告描述时间点事实，不永久代表当前状态。

## 文件命名

```text
docs/audits/YYYY-MM-DD-<audit-name>.md
```

## 必需元数据

- 状态：`Snapshot` 或 `Superseded`；
- 审计日期；
- 代码基线 commit；
- 审计范围与方法；
- 工具版本；
- 替代或纠偏文档。

## 不可变规则

- 不改写原始审计结论以匹配新代码。
- 后续事实通过顶部纠偏说明、勘误或新的审计报告记录。
- 审计与当前代码冲突时，以当前代码、测试和配置事实判断参考文档是否过时。
