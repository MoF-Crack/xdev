## 为什么不再把 ZIP 作为 Windows 更新的唯一格式

此前发布器与更新器约定 canonical ZIP/tar.gz，Windows ZIP 压缩单个可执行程序。正式 RC1 的 ZIP 为 7,460,901 字节，其中 `xdev.exe` 为 19,302,912 字节；压缩降低传输大小，但不是自更新的必要条件。

本次让 Windows 优先选择发布元数据中的 `xdev-windows-amd64-vVERSION.exe`。只在该 EXE 资产完全不存在时兼容旧 ZIP；同名 EXE 重复、无效或未上传完成时明确失败，不隐藏错误转而安装其他包。Linux/macOS 继续使用原归档。发布脚本在 Windows ZIP 之外直接复制同一构建的 EXE，并将其加入必需发布资产与 `SHA256SUMS`；旧 ZIP 保留给只支持归档的客户端。现有 CI 打包和上传步骤自动包含新增文件，本次没有修改 workflow。

这些是后续构建采用的发布规则，不表示当前公开 RC1 已经增加了 EXE 资产。

## Windows 新交互

1. 检查更新，自动匹配运行程序的系统与架构。
2. 点击“下载更新”。后端重新检查版本，下载对应 EXE，校验 `SHA256SUMS` 与 PE 架构，暂存在目标程序的同级独立目录中。原程序保持不变。
3. 校验完成后显示“重启并更新”。下载完成不等同于已安装，也不会自动退出。
4. 用户点击按钮后，先启动独立更新助手并确认其已取得当前进程的真实句柄；随后请求 GUI 正常退出。
5. 助手等待旧进程退出，重新核对旧程序及新文件，备份、替换并从原路径启动新程序，保留配置主目录、工作目录与 `--no-path-fix` 策略。

启动助手失败时窗口继续运行，可重试且不重新下载。暂存文件丢失或内容变化时清除就绪状态，要求重新下载。退出后发现新文件损坏或启动失败，会恢复/启动经过验证的旧程序并携带错误信息；文件被只读句柄占用时也尝试重新打开已校验的旧程序。无法验证或目标变成其他文件时拒绝覆盖。

运行中的旧/新文件使用 Windows 句柄固定身份，SHA 与 PE 校验到按句柄重命名、启动之间不释放阻写保护，避免校验与发布之间的可写窗口。只有后端返回 `ready: true` 才显示重启按钮；只有助手确认就绪才关闭 GUI。关闭弹窗不会丢失准备结果；普通关闭整个应用则丢弃尚未交接的更新。助手已接手后，旧 GUI 的 shutdown 不删除其文件。

Windows 以外仍沿用既有安装与手动重新打开流程，本次不声称实现 Unix 原生重启更新。CLI 的 `Apply` 继续提供直接安装语义。

### 原生窗口完整链路

独立临时程序中实际点击“检查更新 → 下载更新 → 重启并更新”，使用真实 Wails 绑定和原生退出/重启流程。下载后仍为旧 EXE 的哈希；确认重启后旧 GUI 退出码 0，目标哈希等于正式 RC1 程序，新 PID 显示可见 XDev 窗口，`version` 输出 `1.0.0-rc.1`，助手结果为 `updated`。

为了在没有更高公开版本且本机 GitHub 传输不稳定的条件下验证，测试构建仅通过 overlay 将版本声明为 beta.3、开启回环 CDP，并把逻辑 GitHub 请求路由到本地可信 HTTPS 服务。服务直接分发已从正式 RC1 ZIP 提取并核验的 EXE，未关闭 TLS 验证。交付构建不包含这些 overlay 或调试端口。

```text
正式 RC1 ZIP SHA-256：b392d6c41d9a323e11a28d5c19805e2227a3d0dbb34a8db4058c309576c09b47
正式 RC1 EXE SHA-256：319be522d9cfad38bdff0a093949bcff404ae0f14f3ba34a82ff682a5430f51e
```

公网验收确实发现版本并开始下载，但在当前网络条件下传输停滞，未用它证明完整 CDN 下载成功。本地可信服务验收证明的是实际窗口、绑定、直接 EXE 校验、退出后替换和重启链路，不证明所有网络均可访问 GitHub。

## 使用边界

本地候选仍报告 `1.0.0-rc.1`，通过提交、构建时间和 SHA-256 区分；同版本不会作为更高更新重复安装。当前运行的旧安装必须先换为包含此改动的构建，才能使用新交互。本次未修改真实用户程序、根工作区的原始 64 项状态或环境变量；没有创建新的公开 Release。Windows 文件锁可能让助手的自删除失败，此时保留 staging 内的助手和诊断结果，不能将其当作安装成功凭据；成功由替换和重启结果验证。本次未运行 Windows race 或 Linux/macOS 真机 GUI 验收。
