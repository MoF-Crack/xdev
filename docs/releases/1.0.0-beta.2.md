## 变更

- **三主主题**：护眼·雾松、亮色·冰川、暗色·深空；顶部快速切换，设置页以三张主卡展示。
- **F2 品牌**：一个流弧 x 与 dev 组成一体 `xdev` 字标，不重复拼接 X 或品牌文字；应用图标统一为靛紫底、白色流弧 X。
- **响应式工具工作区**：宽度 ≥ 1280 px 时，列表与非遮挡详情面板并排；窄屏使用详情抽屉。
- **原生图标接入**：Windows 构建实际嵌入多尺寸 ICO；macOS DMG 包含带 ICNS 的 `XDev.app`；Linux 桌面入口使用应用图标。五个平台打包任务均在对应 CI runner 上执行成功，归档经 Go updater 消费方验证。
