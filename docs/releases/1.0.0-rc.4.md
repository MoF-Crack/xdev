# XDev 1.0.0-rc.4

- 软件版本：`1.0.0-rc.4`；计划 Tag：`v1.0.0-rc.4`。
- 发布类型：GitHub Pre-release；不覆盖 RC3 或改变 beta.3 的 Latest 兼容入口。
- 基线：最新 RC3 主分支，加经复核的 R20261122 修复。保留 Wails 3、品牌与主题、安装会话及已签名的自更新通道。
- 当前状态：发布准备与整合复验中；尚未宣称 tag 已推送或资产已发布。

## 修复范围

本版收敛 Windows PATH/环境事务、配置保存与改根、卸载和受管 shim、Lua 执行生命周期、下载清理与审计、嗅探恢复与 cron 归属、PM 执行定义信任、远程实例、结构化解包预算和清单版本选择。具体变更见 [Changelog](<../../CHANGELOG.md>)。

原 [R20261122 复核报告](<../audits/2026/2026-11-22-report-remediation.md>) 记录的是移植前 Wails 2 修复阶段的证据；它不替代本次 Wails 3 整合版的测试和发布验收。

## 更新与兼容

- RC3 的校验和签名要求保留：`SHA256SUMS.sig` 覆盖仓库、精确 tag 和校验和原始字节；缺失或失败不能安装。
- Windows 使用直接 EXE，保留 ZIP 供旧更新器兼容。GUI 的「准备更新→重启并更新」流程保留，既有工具与配置不自动清除。
- Linux/macOS 继续 canonical tar.gz 与现有平台安装包；Unix 更新后仍需重新打开应用。
- 未登记的历史 shim 不盲目覆盖，可重新 `xdev use <tool>@<version>` 建立管理记录。
- 未支持的自定义 NSIS/Inno/SFX 明确拒绝。XAR 需要支持该格式的结构化解码器。
- 改根/模式切换是有错误反馈的补偿流程，不承诺跨资源强杀或掉电原子性；迁移旧树保留供恢复。

## 发布验证

验收将在整合源码冻结、重新生成 Wails 3 bindings 后执行。只有正式 tag 流水线完成三平台测试、密钥/签名验证、五平台打包、checksum 签名及发布，且 Release 资产齐全，才记为已发布。

本地已验证最新 RC3 基线 Go 全仓通过，前端 **58 文件 / 451 用例**及构建通过；这些是整合前基线，不是 RC4 完成声明。正式 RC4 测试、提交、tag、workflow run 和资产状态将在实际取得结果后更新。
