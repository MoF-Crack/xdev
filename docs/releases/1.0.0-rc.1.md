## 变更

### Windows GUI 控制台与日志

Windows 桌面 GUI 先初始化文件日志，再调用 `FreeConsole` 解除当前 GUI 进程的控制台关联，随后才启动后台清理等工作。双击启动时不再留下显示后台清理日志的常驻终端；从已有终端进入 GUI 时，仅解除 GUI 自身关联，原终端及其他进程继续工作。单二进制的 CLI、TUI、shim 和维护命令仍保留各自的标准输入输出。

首次设置前的启动日志也写入当前 XDev 主目录下的 `logs/xdev-gui.log`。重复初始化同一路径不会截断早期记录；切换日志路径时关闭旧句柄，结束后恢复调用方的标准日志输出。桌面运行时启动失败会写入日志，并在 Windows 显示错误提示；控制台释放前发生的配置加载错误仍能显示在终端中。

### 自更新采用应用代理

GUI 手动检查、下载安装、启动更新，以及 CLI 手动与启动更新，每次操作都通过 `update.WithProxy` 捕获一份代理配置快照。版本元数据、安装前重新检查、归档下载、`SHA256SUMS`、GitHub 资产 API 回退及 CDN 跳转共用该次操作的网络配置。修改设置后，下一次操作使用新配置，在途操作继续使用原快照。

显式应用代理使用私有 transport，避免修改进程全局客户端或影响其他 App。应用的 `no_proxy` 支持 `NO_PROXY` 风格的主机、域名、IP、CIDR 和可选端口匹配；代理未启用或地址留空时沿用标准环境代理。非法显式代理返回脱敏错误，不静默改为直连。

TLS 证书验证、安全重定向、GitHub 令牌作用域、整体时限、取消、强制 SHA-256 校验、替换与回滚保护继续生效。备用下载仍在既定条件和时限内从头重试，更新成功后仍需用户自行关闭并重新打开 XDev。

## 升级到 RC1

以下 RC1 操作可从已公开的 [RC1 Release](https://github.com/MoF-Crack/xdev/releases/tag/v1.0.0-rc.1) 获取，资产中包含 `SHA256SUMS`。

### 已安装 beta.3

beta.3 已使用 Release 列表与 SemVer 选择更新，能够发现标为 GitHub Pre-release 的更高 RC1。RC1 无需改成非 Pre-release 或 Latest；beta.3 的 Latest 兼容标记继续服务旧更新器。

在设置中点击「检查更新」，或退出 GUI 后运行 `xdev self update`。手动检查不受启动检查的 24 小时节流限制。发现更新后确认「下载并安装」，等待下载、校验、解压和安装完成；若已有启动更新在进行，先等待其结束。也可选择「单独下载归档」自行管理文件。

**beta.3 自更新仍不读取 GUI 设置中的代理。** 在安装并运行 RC1 之前，受限网络下的检查或下载可能失败，即使 GUI 已配置代理也是如此。可使用标准环境代理，或在 RC1 发布后手动下载 RC1 归档；应用代理修复在运行 RC1 后生效。

### 仍在使用较早的 alpha / beta.2

这些旧版只查询 GitHub `/releases/latest`，目前该入口仍指向 beta.3。可先升级到 [beta.3](https://github.com/MoF-Crack/xdev/releases/tag/v1.0.0-beta.3)，再通过新版更新器升级到 RC1；也可在 RC1 发布后直接手动下载 RC1。旧 beta.2 界面没有下载按钮时，CLI 自更新或手动归档方式仍可使用，具体历史操作见 [beta.3 发布说明](<1.0.0-beta.3.md#旧版升级>)。

### 手动下载归档

1. 在本 Tag 的 Release 页面选择系统和 CPU 架构对应的 canonical ZIP / tar.gz，同时下载同一 Release 的 `SHA256SUMS`。
2. 核对下载文件的 SHA-256，与 `SHA256SUMS` 中该文件名对应的摘要一致后再解压。
3. 将归档解压到单独目录，退出旧 XDev 后再运行新程序；如需替换原位置的可执行文件，先确认旧进程已退出。保留原配置目录和已安装工具。
4. 执行新程序的 `version` 命令，确认显示 `1.0.0-rc.1`，再打开 GUI。自更新安装完成后也需要关闭并重新打开应用，当前进程重启前仍运行旧版代码。

Windows PowerShell 示例（待 RC1 发布并完成文件校验后使用）：

```powershell
Expand-Archive -LiteralPath .\xdev-windows-amd64-v1.0.0-rc.1.zip -DestinationPath .\xdev-rc1
.\xdev-rc1\xdev.exe version
```

下载或校验失败不会覆盖原二进制。
