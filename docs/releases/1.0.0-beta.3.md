# XDev 1.0.0-beta.3

- 日期：2026-11-19
- 软件版本：`1.0.0-beta.3`
- 发布 Tag：`v1.0.0-beta.3`
- 状态：待 CI 构建、打包、发布及公开资产校验
- [GitHub Releases](https://github.com/MoF-Crack/xdev/releases)

本版修复旧版自更新漏报较新 beta，以及 GUI 手动检查后没有下载、安装操作的问题。本地整合验证结果见下表；最终 CI 记录与资产下载链接将在发布验证完成后补充，本说明不表示 beta.3 资产已经可下载。

## 变更

- **版本发现**：从 GitHub Release 列表最多读取 5 页、每页 100 项，在该范围内按 SemVer 选择当前平台可安装的最高版本。跳过草稿、无效版本及缺少对应归档或校验和的 Release。
- **更新通道**：当前版本为预发布时，可升级到更高预发布或稳定版本；当前版本为稳定版时，只接受稳定版本号且 GitHub 未标为 Pre-release 的 Release。即使 beta 的 GitHub 标记为非 Pre-release，稳定安装也不会因此升级到 beta。
- **GUI 手动更新**：设置中的「检查更新」发现可用版本后弹出确认框；「下载并安装」执行实际下载、校验、解压和安装，也可通过「单独下载归档」链接自行处理。
- **真实进度与结果**：下载阶段显示已接收字节及可用的总字节，后续显示校验、解压、安装阶段。下载结束不等于安装成功，只有后端明确返回 `applied: true` 才显示已安装。
- **错误与重试**：检查失败不会提示已是最新版；下载或安装失败在对话框内显示具体错误并提供重试。主入口网络超时或临时 HTTP 错误时，可尝试同仓库元数据中的 GitHub 资产 API；两入口共用整体时限，部分下载会清空重来，签名 URL 查询参数不出现在错误提示中。取消、TLS／重定向安全错误、校验和缺失或不匹配不会绕过保护，失败时不覆盖原二进制。
- **并发与交互**：启动自动更新、手动检查及安装共享互斥锁；对话框防止双击重复请求，支持键盘焦点约束与关闭后焦点恢复。手动检查不受启动检查的 24 小时节流限制，`xdev gui` 入口不再提前消耗启动检查额度。

## 旧版升级

旧版检测仅查询 GitHub 的 `/releases/latest` 元数据。此前该元数据可能指向 alpha.3，即使本机已运行 beta.2，也无法据此发现较新的 beta。新版本的列表发现逻辑和 GUI 下载入口都需要先升级程序才会生效，修改 Release 元数据不会给已安装的旧程序增加按钮。

为兼容已安装 beta.2，beta.2 的 GitHub Release 已调整为非 Pre-release 的 Latest，原 Tag 与资产保持不变；beta.3 待 CI 发布完成后也将标为非 Pre-release 的 Latest。软件版本与 Tag 仍为 `1.0.0-beta.3` / `v1.0.0-beta.3`。SemVer 中的 `beta` 仍表示预发布，GitHub 的非 Pre-release / Latest 标记是兼容旧检测器的发布选择，不改变版本号语义。

如果旧 beta.2 界面没有下载按钮，在 beta.3 资产发布后按以下步骤升级：

1. 从 [GitHub Releases](https://github.com/MoF-Crack/xdev/releases) 选择 beta.3 对应系统、CPU 架构的归档，并使用同一 Release 的 `SHA256SUMS` 核对下载文件。
2. 将归档解压到单独目录，保留原配置目录与已安装工具。Windows ZIP 内的单个 `xdev.exe` 同时提供 GUI、TUI 和 CLI。
3. 退出仍在运行的旧 XDev，再使用解压后的新可执行文件。若需替换原位置的可执行文件，先确认旧进程已经退出。
4. 用新程序的 `version` 命令确认版本，再打开 GUI；升级后继续使用原配置目录。

Windows PowerShell 示例（先从发布页下载 ZIP，并完成校验；运行新程序前退出旧应用）：

```powershell
Expand-Archive -LiteralPath .\xdev-windows-amd64-v1.0.0-beta.3.zip -DestinationPath .\xdev-beta3
.\xdev-beta3\xdev.exe version
```

## 升级后的自更新

在设置中点击「检查更新」可主动联网检查，不受启动自动检查的 24 小时节流限制。发现更新后确认「下载并安装」，等待下载、校验、解压与安装完成；如果同时已有启动更新在进行，请等待其结束后再检查。需要自行管理文件时，可使用对话框中的「单独下载归档」。

安装成功后请自行关闭并重新打开 XDev，应用不会自动关闭或重启。当前进程在重新启动前仍运行旧版本代码；成功提示只确认新程序已安装。更新保留已有配置目录与已安装工具。
