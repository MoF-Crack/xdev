### 票 27 版本比较器全序化（PR-26）

**改动**：`internal/manifest/manifest.go`（versionReleaseNewer :615-627）、`manifest_test.go`
**步骤**：
1. 比较器改全序元组：`CompareSemver(a,b) != 0 → 用其结果；else 日期 parse 均成功且不等 → 日期；else 字符串比较`——注意**次序**：v1 是「日期优先」，新语义是 **semver 优先、日期仅作 semver 等值时的 tiebreak**？——**否**：方案 P1-10 定义的元组为 `CompareSemver → 日期（缺省零值）→ 字符串`，即 **semver 为主键**（「2.0.0 排顶」守卫判据此），日期降为同 semver 的次键。与既有测试「日期优先于 semver」直接矛盾 → **显式反转** TestSortVersionsByRelease_DatedNewestBeatsOlderSemver（manifest_test.go:1247-1256）。
2. 传递性验证：全序元组天然传递（方案 §5 P1-10 三元组守卫）。
3. release note 条目：lua 5.5.0/java "26" 等日期倒挂数据下，GUI 版本列表顶部与 UpdatePackageManager 实装版本变化（方向正确——装最新 semver）。
4. 「日期缺省零值」语义（同 semver 无日期者恒排后）写进测试。
