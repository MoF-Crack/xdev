# 归档 URL 豁免清单（供 `xdev manifest check-urls --allow-file` 与 url-liveness 工作流使用）
#
# 用途：把**已知不可达且已确认接受**的归档 URL 写在这里，让巡检不为它们报红。
# 每行一条完整 URL；`#` 之后为注释；空行忽略。
#
# 使用纪律：
#   - 每条豁免都应当有对应工单/原因（写在注释里），否则就是把真实缺陷掩盖成"已知问题"；
#   - 上游改名类问题应当**修 URL**（见 manifests/llvm.yaml、manifests/zig.yaml 的注释），
#     而不是加进豁免清单；
#   - 本清单当前为空：2026-09-13 实测 495 条归档 URL 中，唯一确定性失败是 llvm 22.1.8 与
#     zig 0.15.1 的 4 条旧命名 URL（已在本批直接修好）；其余 err 均为本机网络受限
#     （archive.apache.org 等，CI 出口可达），因此无需豁免。
