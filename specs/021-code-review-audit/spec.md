详细发现项与任务拆分见同目录 `report.md` 与 `checklist.md`。本文件是活跃规格目录要求的 `spec.md` 权威入口。

## 目标

对 `internal/`、`cmd/`、`frontend/src/`、`go.mod` 与 `manifests/` 做一次静态审查，产出可跟踪的重构与安全修复清单，并按 checklist 分阶段落地。

## 范围

- 纯重构（零行为变化）：目录复制、归档后缀、缓存分类、伴生文件删除
- 安全与正确性：命令注入、路径穿越、签名校验、依赖升级
- 不在本 Spec 重做产品功能（嗅探、包管理器、IDE 管理由后续 Spec 覆盖）

## 验收

1. `report.md` 列出的 P1 重构项已落地或明确延期记录
2. `checklist.md` 中已勾选项有对应测试或构建证据
3. `go test ./... -short` 与前端构建不被本审查引入的回归打断
